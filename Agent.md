# Agent.md

## Название проекта

Market Mentor

## Идея

Телеграм-бот для инвестора на фондовом рынке, который собирает и показывает свежие рыночные данные и новости. Он помогает быстро получить обзор состояния рынка и понять важные события.

## Целевая аудитория

Инвесторы на фондовом рынке, которые хотят иметь быстрый рыночный обзор и новости в Telegram.

## Проблема пользователя

Инвестор не успевает следить за рынком и новостями в одном месте, нужны короткие и понятные подсказки по состоянию рынка.

## Основной сценарий

1. Пользователь запускает бота командой `/start`.
2. Бот приветствует и предлагает выбрать обзор рынка или новости.
3. Пользователь вводит команду `/market` для получения текущего обзора рынка.
4. Бот запрашивает и показывает ключевые данные по рынку.
5. Пользователь вводит команду `/news` для свежих финансовых новостей.
6. Бот отвечает кратким списком важных новостей или аналитических тезисов.

## Команды бота

- /start — приветствие и короткая инструкция по боту
- /help — помощь и список команд
- /market — получить обзор рынка
- /news — посмотреть последние финансовые новости
- /reset — начать заново или очистить текущую сессию

## Использование GigaChat

GigaChat отвечает за анализ текста и формирование кратких подсказок:
- делает краткий обзор рыночных данных;
- анализирует новости и выделяет важные тезисы;
- формирует понятные выводы для пользователя.

## Использование Supabase

В Supabase хранятся данные пользователя и история запросов для простого учета.

### users

- telegram_id
- имя пользователя
- настройки уведомлений или предпочтений
- время регистрации

### sessions или requests

- id запроса
- telegram_id пользователя
- тип запроса (`market`, `news`)
- текст запроса или команда
- время запроса

### messages или history

- id сообщения
- telegram_id пользователя
- вопрос или команда
- ответ бота
- время сообщения

## Минимальная версия MVP

Самая простая версия: бот получает команду `/market` и показывает обзор рынка, а команда `/news` выводит свежие новости. GigaChat используется для генерации краткого анализа, Supabase хранит пользователей и историю запросов.

## Возможные улучшения

- добавление команды `/insight` для простых инвестиционных подсказок;
- сохранение избранных акций и напоминаний;
- поддержка персональных настроек новостей;
- расширенный анализ по конкретным тикерам;
- хранение пользовательских заметок.

## Технический стек

- Python
- aiogram 3.0
- GigaChat

- python-dotenv

## Итоговое описание для разработки

Создать Telegram-бота для инвестора, который по команде показывает обзор фондового рынка и финансовые новости. aiogram обрабатывает интерфейс Telegram, GigaChat формирует аналитику и краткие выводы, Supabase хранит пользователей и историю запросов. MVP включает команды `/start`, `/help`, `/market`, `/news`, `/reset`.
